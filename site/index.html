07 / The rules

Exactly what's counted.

Exact counted directly from git or GitHub. Close exact count, but a small part of the credit is inferred. Estimate based on wording, not proof.

StatWhat's countedCertainty
Merged PRsSolidCraft and FieldCraft squash each PR into one commit ending in "(#number)", authored by the PR's author. PCBCraft and CamCraft keep merge commits titled "Merge pull request #n from owner/branch", credited to the branch owner.Exact for SolidCraft and FieldCraft
PCBCraft and CamCraft PRsAs above. PRs from branches inside the project's own repo don't name a person, so they go to the author of the branch's last commit.Close
Last 7 daysMerged PRs whose merge landed on main in the 7 days before the last update.Exact
CommitsCommits on main they authored, merge commits left out. SolidCore's repo copies SolidCraft's kernel commits, so those count once.Exact
Kernel commitsCommits that changed SolidCraft's geometry-kernel folders (solidcore, kernel, smlib, geom, goldens, difftest) and kernel test cases.Exact
TriageIssues they commented on, in any of the repos. It counts issues, not individual comments.Exact
IssuesIssues they opened in any of the repos.Exact
ReviewsOther people's PRs they left at least one review on. Plain comments aren't reviews.Exact
Streak, days, best dayUTC days with at least one commit they authored on main in any repo; a streak is consecutive days.Exact
Main areaThe area, by files changed, with most of their commits, docs and tests left out.Exact for folders; the grouping is a choice
Rank movementChange in merged-PR rank among contributors since the last update of the previous UTC day.Exact
IdentityCommits are tied to people by GitHub account. A commit email GitHub can't tie to an account joins one only when the same full name was used on that account's linked commits; the few left over stay under the email's name.Exact for accounts; Close for name matches
